# daily-build-feed
The Daily Build — daily AI business audio briefing, in two editions:

- **Private estate edition** (`pending/` → `build-episode.yml`) — Dean's own briefing,
  posted to his private feed on deanlynn.com. Style: `STYLE.md`.
- **Member edition, "The Daily Build — with Dean Lynn"** (`members/pending/` →
  `build-member-edition.yml`) — read by Dean's ElevenLabs voice clone, posted to
  deanlynn.com as a draft. Style: `STYLE-MEMBERS.md`.

Daily procedure: `RUNBOOK.md`. The legacy GitHub Pages feed stays on until the repo
variable `PUBLISH_PAGES` is set to `false` (see RUNBOOK.md, Architecture).
Also in this repo: JT Morning Brief (`bedford/`).
